# Commit Message

## Short

```text
<type>: <summary>
```

## With Body

```text
<type>: <summary>

- <change>
- <change>
- <change>

Verified: <command/check>
```

## Types

- `feat`: user-visible or workflow-visible addition
- `fix`: bug or broken behavior fix
- `docs`: documentation-only change
- `refactor`: behavior-preserving structure change
- `test`: test-only change
- `chore`: maintenance change
