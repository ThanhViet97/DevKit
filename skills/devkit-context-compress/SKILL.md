# DevKit Context Compress

## Goal

Reduce long context into a compact, reusable summary without losing decisions or constraints.

## When To Use

Use this skill when:

- Session context is long.
- Repo memory needs a compact summary.
- A handoff note is needed.
- A plan/spec/review thread needs compression.

## Preserve

- final decisions
- active version
- scope and non-goals
- constraints
- open questions
- blockers
- file paths
- verification results
- next actions

## Remove

- repeated discussion
- abandoned options
- casual phrasing
- non-actionable details

## Output Shape

```text
State:
- ...

Decisions:
- ...

Files:
- ...

Open:
- ...

Next:
- ...
```
